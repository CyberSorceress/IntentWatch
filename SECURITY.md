# Security Policy

## Supported Versions

IntentWatch is an academic cybersecurity research and auditing platform developed for **Course 24CYS404 (Android Application Development)** under the supervision of **Dr. S. Udhayakumar**.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Intended Purpose & Ethical Use

IntentWatch is engineered exclusively for:
1. Authorized local vulnerability assessments on devices you own or have explicit written authorization to test.
2. Academic instruction and research in Android mobile application security.
3. Developer self-auditing to identify and remediate deep-link and intent redirection flaws prior to production deployment.

Do not use this software for unauthorized testing or malicious intent interception.

## Reporting a Vulnerability

If you discover a security vulnerability within IntentWatch itself:
1. Please open an issue or reach out to the project maintainers directly.
2. Provide a clear description, reproduction steps, and impact assessment.
3. We follow coordinated vulnerability disclosure and will acknowledge receipt within 48 hours.
